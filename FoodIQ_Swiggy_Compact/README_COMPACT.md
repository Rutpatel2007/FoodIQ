# FoodIQ Swiggy Compact Research Package

This package was reduced to make it easier to upload while retaining the source set and extracted research material.

## Included
- All 6 source PDFs, under `PDFs/`.
- Every non-PDF file from the original research archive, preserved at its original relative path.
- `PDF_COMPRESSION_REPORT.json`, documenting the compression method and page count.

## Important image-quality note
PDFs were recompressed using a screen-oriented profile. The Eternal April 2025 company overview was converted to a 55-DPI image PDF to reduce its unusually large image payload. This lowers zoom quality for diagrams and small print. The package's extracted text, page-level text and OCR files are retained where they existed in the original archive. For precise visual inspection of small table cells, use the original uploaded PDF if available.

No quarters or non-PDF research files were intentionally omitted.
