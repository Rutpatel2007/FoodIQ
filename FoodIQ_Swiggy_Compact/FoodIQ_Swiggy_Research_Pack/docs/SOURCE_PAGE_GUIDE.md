# Source page guide

See `sources/source_page_index.csv` for every page in all six PDFs. `pdf_page` is the 1-indexed physical PDF page (the page number a PDF viewer displays); `printed_page` is the page label printed in the shareholder letter. Use both when citing a source. `sources/page_text/all_pages.jsonl` contains each page's extracted text and section hint. For chart/table cells, verify against the rendered original PDF.

Pages with the most relevant data are generally physical pages 4–9 (quarter highlights and KPI histories), 10–15 (management Q&A), 16 (financial reconciliation), 17–21 (definitions), and 22–24 (statutory financial statements). Page positions can differ by letter; consult the index rather than hard-coding assumptions.
